# Native Canon rendering examples

These PNGs derive from the **CC0 raw.pixls.us Canon PowerShot G7 X Mark III sample 6053**. The original contributor is not identified by the retained listing. Full source and checksum details are in [the source credits](../source/CREDITS.md).

The images were rendered offline with Canon Picture Style Editor 1.33.10's native RAW engine, using the original RAW and the supplied PF3s. They are **not camera-produced JPEGs**. [The validation report](../../research/canon-native-validation.json) records settings, exact file hashes, and measured limits.

No Canon software is included. These example photographs are CC0; the film model's data license is documented separately and does not change the license of a rendered photograph.
