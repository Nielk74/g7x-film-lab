Five film-inspired looks: Portra 400, Gold 200, Ektar 100, Pro 400H and Tri-X 400.

Download **G7X-Film-Lab-0.1.0.zip**, extract it, and open **START-HERE.html**. The pack contains five ready-made Canon PF3 profiles, five 65³ sRGB CUBE LUTs, an offline gallery with 25 examples, installation instructions, native Canon software previews, validation records and licenses.

Film responses use attributed manufacturer-data-based Fotufilm profiles with disclosed display adaptation, neutral print timing and soft gamut containment. The assets pass local format checks, native Canon parsing/readback and the G7 X III model compiler offline.

Physical USB registration and camera JPEG output are untested. These are film-inspired renderings, not a measured match to a particular film scan. Canon desktop previews use the file’s parametric approximation; camera compilation consumes its full sampled table. Grain and halation are outside a 3D LUT.

The G7 X III stores three User Def. styles at a time. Canon’s registration tool is downloaded separately from Canon. No firmware or vendor software is included.
